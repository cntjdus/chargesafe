# ChargeSafe

> 전동휠체어 배터리 화재 예방을 위한 스마트 충전 도킹스테이션

**ChargeSafe**는 전동휠체어 및 전동스쿠터 사용자의 실내 충전 안전을 높이기 위한 IoT 기반 스마트 충전 도킹스테이션입니다.  
충전 중 배터리의 온도, 전류, 전압, 연기, 가스 등의 이상 징후를 실시간으로 감지하고, 위험 상황 발생 시 자동으로 충전을 차단하며 보호자에게 알림을 제공합니다.

## Project Overview

전동휠체어는 장애인과 고령자의 이동권을 보장하는 중요한 보조기기입니다.  
하지만 실내에서 장시간 충전하는 경우 배터리 과열, 과충전, 전기적 이상, 화재 등의 위험이 발생할 수 있습니다.

ChargeSafe는 이러한 문제를 해결하기 위해 전동휠체어 충전 과정에서 발생할 수 있는 위험 신호를 조기에 감지하고, 자동 차단과 알림 기능을 통해 사용자와 보호자가 더 안전하게 충전할 수 있도록 돕습니다.

<br/>

## Problem

전동휠체어 및 전동스쿠터는 주로 가정, 요양시설, 복지관, 병원, 공동주택 등 실내 공간에서 충전됩니다.  
특히 고령자나 장애인이 혼자 충전하는 경우, 배터리 이상 징후를 즉시 인지하기 어렵고 야간 또는 장시간 충전 중 사고가 발생하면 빠른 대응이 어렵습니다.

따라서 다음과 같은 문제가 발생할 수 있습니다.

- 충전 중 배터리 과열 및 과충전 위험
- 전류·전압 이상으로 인한 전기적 사고 가능성
- 연기 또는 가스 발생 시 조기 감지의 어려움
- 보호자의 원격 확인 및 즉각 대응 어려움
- 실내 화재 발생 시 인명피해로 확대될 가능성

<br/>

## Solution

ChargeSafe는 전동휠체어를 도킹스테이션에 연결하면 충전 상태를 실시간으로 모니터링합니다.  
센서 데이터를 기반으로 위험도를 판단하고, 이상 상태가 감지되면 자동으로 충전을 중단합니다.

### 핵심 아이디어

> 사용자가 매번 안전수칙을 기억하지 않아도, 충전 시스템이 위험을 먼저 감지하고 자동으로 대응한다.

<br/>

## Main Features

### 1. 실시간 충전 상태 모니터링

충전 중 배터리 상태를 실시간으로 측정합니다.

- 배터리 온도
- 충전 전류
- 충전 전압
- 연기 감지
- 가스 감지
- 충전 진행 상태

<br/>

### 2. 위험도 판단 알고리즘

단일 센서값만으로 판단하지 않고 여러 신호를 종합해 위험도를 분류합니다.

| 단계 | 상태 | 동작 |
|---|---|---|
| 정상 | 충전 상태 안정 | 충전 유지 |
| 주의 | 온도 상승 또는 전류 변화 감지 | 냉각팬 작동, 상태 표시 |
| 경고 | 온도·전류·전압 이상 패턴 감지 | 부저 및 보호자 알림 |
| 위험 | 고온, 연기, 가스 등 위험 신호 감지 | 충전 자동 차단 |

<br/>

### 3. 자동 충전 차단

위험 상태가 감지되면 릴레이를 통해 충전 전원을 자동으로 차단합니다.  
이를 통해 과열이나 화재로 이어질 가능성을 줄입니다.

<br/>

### 4. 냉각 및 경고 시스템

온도 상승이 감지되면 냉각팬을 작동시키고, 위험 상황에서는 부저와 LED로 사용자에게 경고합니다.

- 냉각팬 작동
- LED 상태 표시
- LCD 상태 출력
- 부저 경고음
- 음성 안내

<br/>

### 5. 보호자 앱 알림

이상 상황 발생 시 보호자에게 알림을 전송합니다.

예시 알림 문구:

```txt
전동휠체어 충전 중 이상 상태가 감지되었습니다.
안전을 위해 충전이 자동으로 차단되었습니다.
즉시 상태를 확인해 주세요.
```

<br/>

### 6. 충전 이력 관리

충전 상태와 사고 발생 이력을 저장해 보호자가 확인할 수 있도록 합니다.

- 충전 시작 시간
- 충전 종료 시간
- 최고 온도
- 전류·전압 변화 기록
- 자동 차단 발생 여부
- 위험 발생 원인

<br/>

## Target Users

ChargeSafe의 주요 사용 대상은 다음과 같습니다.

- 전동휠체어 또는 전동스쿠터를 사용하는 장애인·고령자
- 보호자, 가족, 요양보호사
- 요양원, 복지관, 장애인 시설, 병원
- 공동주택 공용 충전 공간
- 야간 또는 장시간 충전이 필요한 사용자

## System Architecture

ChargeSafe는 전동휠체어가 도킹스테이션에 연결되면 센서 데이터를 수집하고, 소프트웨어가 위험도를 판단한 뒤 자동 제어와 보호자 알림을 수행하는 구조입니다.

| 단계 | 구성 요소 | 역할 |
|---|---|---|
| 1. 도킹 및 충전 시작 | 전동휠체어, 도킹스테이션 | 사용자가 전동휠체어를 도킹하면 충전 연결 상태를 인식하고 충전을 시작 |
| 2. 센서 데이터 수집 | 온도 센서, 전류 센서, 전압 센서, MQ-2 센서 | 충전 중 배터리의 온도, 전류, 전압, 연기, 가스 데이터를 실시간으로 측정 |
| 3. 데이터 처리 | ESP32 / Arduino | 센서값을 수집하고 노이즈를 보정한 뒤 소프트웨어 판단 로직으로 전달 |
| 4. 위험도 판단 | Risk Detection Logic | 수집된 데이터를 기반으로 정상, 주의, 경고, 위험 상태를 분류 |
| 5. 자동 제어 | 릴레이, 냉각팬, LED, LCD, 부저 | 위험도에 따라 충전 유지, 냉각팬 작동, 경고 출력, 충전 차단 수행 |
| 6. 서버 연동 | Backend / Database | 충전 상태, 센서 데이터, 차단 이력, 위험 발생 기록을 저장 |
| 7. 사용자 알림 | Web/App Dashboard | 보호자가 실시간 충전 상태를 확인하고 이상 상황 발생 시 알림 수신 |

<br/>

## Software Logic
위험도 판단 예시
IF 연기 또는 가스 감지:
    위험 단계
    충전 차단
    보호자 긴급 알림

ELSE IF 온도 기준 초과 AND 전류 이상:
    경고 단계
    부저 작동
    보호자 알림

ELSE IF 온도 상승 속도 증가:
    주의 단계
    냉각팬 작동

ELSE:
    정상 충전 유지

## Expected Effects

- 사용자 안전성 향상: 온도, 전류, 전압, 연기, 가스 등 여러 신호를 함께 감지하여 단일 센서 오작동 가능성을 줄이고 충전 중 사고를 조기에 예방합니다.
- 실내 화재 예방: 과충전, 고온 방치, 장시간 충전으로 인한 위험을 자동 차단과 알림으로 보조하여 실내 화재 가능성을 낮춥니다.
- 보호자 불안 감소: 장애인·고령자가 혼자 충전하는 상황에서도 보호자가 앱으로 충전 상태를 확인할 수 있어 빠른 대응이 가능합니다.
- 접근성 향상: LED, LCD, 음성 안내, 부저, 앱 알림을 함께 제공해 사용자의 감각·인지 특성에 따라 다양한 방식으로 정보를 전달합니다.
- 확장성: 가정용뿐 아니라 복지관, 요양원, 장애인 시설, 병원, 아파트 공용 충전구역에도 적용할 수 있으며, 여러 대의 전동휠체어를 관리하는 다중 충전 스테이션으로 확장 가능합니다.
